# Observador 1.56.0 / 67 — Respaldo automático y acceso rápido

Fecha: 2026-11-16. Base `feature/1.55.0-vehiculo-integrado` (`588d437`). Room 24, sin migración.

## Qué se implementa y para qué

- **Respaldo automático semanal.** El conductor elige una carpeta (selector de Android, permiso persistente) y WorkManager ejecuta cada 7 días, con batería y almacenamiento no bajos, el mismo respaldo completo que el manual. El archivo escrito se vuelve a leer y se verifica. Un fallo se notifica y se muestra; un archivo a medio escribir se quita para que nunca se ofrezca como respaldo. Los automáticos no llevan contraseña: el cifrado sigue disponible en el respaldo manual.
- **Lista de respaldos.** Todos los respaldos de Observador de esa carpeta, manuales o automáticos y cifrados o no, con fecha, tamaño y espacio total, y «Restaurar» con la misma revisión y copia de seguridad previa que siempre. Ninguno se borra solo.
- **Botón rápido.** «Observador» en los ajustes rápidos: activo = leyendo (con el modo), inactivo = en pausa. No cambia el modo de operación.
- **Widget.** Lectura o pausa y modo, resumen de las gomas y fecha del último respaldo. Toca para abrir la app.
- **Evidencia para la X de Uber.** En modo Automático, cuando una oferta de un sector «Cerrar» llega al final de su cuenta atrás, se escribe la pantalla completa de Uber (`cierres/evidencia-AAAA-MM-DD.txt`): cada nodo con clase, texto, descripción, id, si se puede tocar y posición, más la región de la tarjeta, los botones con forma de icono dentro de ella y la decisión tomada. Ajustes › Sectores muestra cuántas hay y exporta un .zip.

## Para activar el cierre real con la X

1. Modo Automático, con al menos un sector en «Cerrar».
2. Trabajar hasta que lleguen 3 o más ofertas de esos sectores. Observador no toca nada mientras siga en simulación.
3. Ajustes › Sectores › «Exportar evidencia» y guardar el .zip en `D:\ubercalculador\viajes\`.
4. Con esa evidencia se identifica el botón real, se ajusta `CloseTarget` (por descripción, id o forma, siempre dentro de la tarjeta y lejos de «Aceptar») y se pone `VALIDATED = true` en una versión propia, con pruebas sobre esas pantallas reales.
