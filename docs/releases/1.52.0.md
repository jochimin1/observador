# Observador 1.52.0 / 63 — Entrega estable y mantenimiento continuo

Fecha: 2026-11-15. Base `release/1.51.0`. Rama de implementación `feature/1.52.0-entrega-estable`. Room 21, identidad `3e8586c0da9a9b6f181c00e549cc40ff`, sin migración. Entrega local; no publicada en el remoto ni instalada por el agente en el teléfono.

## Qué se implementa y para qué

- Workflow de GitHub para ramas, PR, etiquetas y ejecución manual: compilación debug/release, pruebas JVM/Python, lint, notas, catálogo y esquemas. Guarda informes y APK de QA. La instrumentación tiene matriz API 30 y 36 y utiliza una compilación anterior desde etiqueta para probar la actualización.
- Verificador de APK: lee la identidad del archivo real con aapt y valida su firma con apksigner. Rechaza paquete, versión o código equivocados, certificado diferente al anterior y APK debug cuando se exige release. Emite SHA-256, tamaño, certificado y procedencia del código en JSON. No infiere compatibilidad de una rotación de claves.
- Controles de fuente: catálogo sin duplicados, versión/código actuales, incremento de código, notas para el conductor, cobertura de changelog y esquemas históricos conservados. La comparación de esquemas ignora únicamente formato JSON/finales de línea.
- Firma release mediante cuatro variables externas; configuración parcial o almacén dentro del repositorio rechazados. No hay claves nuevas de producción ni credenciales en Git. Sin configuración externa, release compila sin firmar y no se ofrece como instalable.
- Ejecutores locales con logs y resultado explícito: `validate_release.py`, `check_release.py`, `prepare_previous.py` y `test_emulator.py`. Este último solo permite un serial de emulador y confirma la propiedad de emulación antes de instalar. Las respuestas fallidas o vacías de instrumentación no pasan aunque adb salga con código cero.
- Prueba de actualización: registro de QA con nombre, dirección, coordenadas/ruta y búsqueda, y tema real guardado; instalación `-r` entre preparación y comprobación. La base anterior puede reinstalarse con `-d` exclusivamente en el emulador debug para repetir el ensayo, sin borrar sus datos.
- Prueba de cadena de migraciones desde cada esquema exportado (4 a 20) hasta 21, con oferta y precio conservados, validación de todas las tablas e integridad SQLite. Las versiones 1 a 3 no tienen esquemas exportados y no se declaran cubiertas por esta prueba.
- Variante `optimized` experimental con reducción de código/recursos, separada de la entrega normal; conserva los archivos de mapping. La entrega habitual sigue sin minificación hasta probar sus recorridos completos.

Procedimiento, firma, controles y lista de jornada: [VALIDACION.md](VALIDACION.md).

## Comprobar e instalar la entrega debug compatible

```powershell
Set-Location D:\ubercalculador
git switch release/1.52.0
if ($LASTEXITCODE -ne 0) { throw 'No se pudo seleccionar la entrega' }
python scripts/version_refs.py --check
if ($LASTEXITCODE -ne 0) { throw 'Referencias no válidas' }
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
python scripts/validate_release.py --previous-apk build/releases/1.51.0/Observador-1.51.0-62-debug.apk
if ($LASTEXITCODE -ne 0) { throw 'No instalar: revisar la validación' }

$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
$serial = 'rsqojruspnprs4mv'
& $adb -s $serial get-state
if ($LASTEXITCODE -ne 0) { throw 'Revisar conexión y autorización USB' }
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
$before = "build/private-backups/1.52.0/$stamp-before"
python scripts/snapshot_phone.py $serial $before
if ($LASTEXITCODE -ne 0) { throw 'Revisar copia o terminar el viaje abierto' }
& $adb -s $serial install -r app/build/outputs/apk/debug/app-debug.apk
if ($LASTEXITCODE -ne 0) { throw 'Instalación fallida; no desinstalar' }
& $adb -s $serial shell am start -n com.ubers.observador/.MainActivity
if ($LASTEXITCODE -ne 0) { throw 'Revisar apertura' }
Start-Sleep -Seconds 10
& $adb -s $serial shell dumpsys package com.ubers.observador | Select-String 'versionCode|versionName'
# Debe mostrar versionCode=63 y versionName=1.52.0
$after = "build/private-backups/1.52.0/$stamp-after"
python scripts/snapshot_phone.py $serial $after
if ($LASTEXITCODE -ne 0) { throw 'Revisar comprobación posterior' }
Get-Content "$before/counts.json"
Get-Content "$after/counts.json"
# Integridad ok, esquema 21 y registros anteriores conservados.
```
