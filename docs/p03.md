# Continuamos con P03 · Rentabilidad Real y Costo Operativo.
Este prompt parte de que P01 ya centraliza los viajes y P02 aporta distancia GPS, duración, telemetría y reconstrucción real. La misión de P03 es responder con claridad:
¿Cuánto dinero realmente me dejó cada viaje, cada hora y cada jornada después de considerar los costos de trabajar?

Aquí hay que ser especialmente cuidadosos con los términos. P03 debe separar ingreso bruto, costos observados, costos imputados y beneficio operativo; nunca presentar una estimación como si fuera dinero efectivamente cobrado o gastado.
