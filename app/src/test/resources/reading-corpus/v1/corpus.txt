# Observador · corpus de lectura v1 (1.38.0)
#
# Pantallas de Uber Driver saneadas, en el orden de los nodos de accesibilidad. Ningún nombre,
# dirección ni importe pertenece a un viaje real. Las cifras de los casos «sintetico» se escribieron
# a mano siguiendo las firmas conocidas; los casos «captura» deben venir de capturas reales pasadas
# por SnapshotSanitizer y revisadas antes de añadirse. Este v1 aún no contiene casos «captura».
#
# Formato de cada caso:
#   === <id>                       inicio del caso
#   origen: sintetico | captura    procedencia
#   secuencia: <nombre>            opcional; los casos de una secuencia se reproducen en orden
#   pantalla: <UberScreenType>     opcional; tipo esperado del clasificador
#   estado: <RideLifecycleState>   opcional; estado esperado tras reproducir este paso
#   lectura: <OfferParseStep>      opcional; resultado esperado del lector de la tarjeta
#   precio: <número>               opcional; precio que debe leerse
#   dinero: <FinancialScreenType>  opcional; tipo de pantalla de dinero esperado
#   T: <texto>                     nodo de texto
#   B: <texto>                     botón pulsable
